Sally Home Connect

Sally Home Connect est une solution domotique locale pour Windows permettant de piloter simplement les équipements d'un logement.

Elle permet notamment de gérer :

les éclairages ;
les volets roulants ;
le chauffage ;
les relais ;
les équipements EnOcean ;
les équipements Zigbee ;
les scénarios ;
la commande vocale.

Installation
Téléchargez SallyHomeConnect-Setup-Beta-60j-v0.1.1.exe.
Exécutez l'installateur.
Suivez les étapes d'installation.
Lancez Sally Home Connect depuis le raccourci créé sur le Bureau.

Après son lancement, Sally s'ouvre dans votre navigateur à l'adresse :

https://127.0.0.1:3443

Une domotique locale

Sally Home Connect est conçu pour fonctionner localement, sans nécessiter de compte utilisateur en ligne.

Selon votre installation, un dongle USB EnOcean et/ou une passerelle Zigbee compatible peuvent être nécessaires pour piloter des équipements réels.
