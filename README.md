# Sally Home Connect

Sally Home Connect est une solution domotique locale pour piloter simplement un logement.

Elle permet notamment de gérer :

- les éclairages ;
- les volets roulants ;
- le chauffage ;
- les relais ;
- les équipements EnOcean ;
- les équipements Zigbee ;
- les scénarios ;
- la commande vocale.

## Bêta Windows

Cette version est une bêta destinée aux premiers testeurs.

- Windows 10 ou Windows 11 64 bits ;
- essai gratuit de 60 jours ;
- aucun compte en ligne nécessaire ;
- fonctionnement local ;
- Node.js est inclus dans l’installation.

## Installation

Téléchargez le fichier `SallyHomeConnect-Setup-Beta-60j.exe` depuis la page des versions (**Releases**) de ce dépôt, puis exécutez-le.

L’installateur crée un raccourci Sally Home Connect sur le Bureau.
